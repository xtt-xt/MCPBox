# MCP 文件盒 隐私政策
版本 v2 ｜ 生效日期：2026 年 10 月 24 日

## 一、总则
1.1 本政策说明 MCP 文件盒（以下简称「本应用」）会接触哪些数据、存放在哪里、在什么情况下离开你的设备。它是《用户协议》的组成部分。
1.2 本应用的定位是「在你自己的手机上跑一个服务」。它不提供账号体系，没有开发者服务器，也不存在「注册」「登录」「云端同步」这些环节。

## 二、不收集的信息
2.1 不收集设备标识符（IMEI、Android ID、序列号、广告 ID 等）。
2.2 不收集你的文件内容、目录结构、文件名清单，也不把它们上传到任何地方。
2.3 不收集位置、通讯录、短信、通话记录、相册内容、已安装应用列表。
2.4 不含统计上报、崩溃上报、广告、推广或行为追踪组件。没有第三方分析 SDK。

## 三、数据存放位置
本应用产生的所有数据都写在**本机应用私有目录**（Android 的 `/data/data/<包名>/` 下），其他应用无法直接读取：

3.1 设置、访问令牌、端口、权限规则、工具包状态 —— 存放在本机 SharedPreferences 中。
3.2 会话（工具包激活记录）—— `profiles/` 目录下的 JSON 文件。
3.3 记忆库（AI 写入的实体、观察、关系）—— `memory/graph.json`。
3.4 使用统计（每日请求数、运行时长、启动次数）—— `stats/stats.json`。
3.5 自定义背景 —— 你选择的图片或视频副本，存在私有目录内。
3.6 自定义工具、自定义图标 —— 同样在私有目录内。

除你主动导出或备份外，以上数据不会被本应用发到本机之外。

## 四、权限用途
4.1 **文件访问**（所有文件访问 / 存储权限）：用于按你的授权读写手机存储中的文件，以及 MCP 文件通道的上传下载。可在权限页限制为仅应用私有目录或指定目录。
4.2 **悬浮窗**：用于审批弹窗、内置浏览器的悬浮球与页面面板。没有它则审批退化为通知栏。
4.3 **通知**：用于审批提醒、前台服务状态。通知内容只包含操作摘要（工具名、路径），不含文件内容。
4.4 **忽略电池优化 / 开机自启 / 唤醒锁**：用于在后台保持服务运行、开机后恢复监听。
4.5 **Root / Shizuku**：仅在你主动授权后用于执行命令与界面自动化。授权与否、授权范围都由你决定，可随时撤销。
4.6 以上权限均需你手动授予，本应用不会绕过系统弹窗自行获取。

## 五、网络访问
本应用只在下列情形使用网络：

5.1 **监听本机端口**（默认 8720）。服务默认只允许本机（127.0.0.1）访问；开启局域网访问后，同网络的设备可连入。
5.2 **你主动检查更新**时，向 GitHub 的公开接口查询最新版本号。请求只带版本信息，不带设备标识或使用数据。
5.3 **内置浏览器**：你或 AI 让它打开的网页，其请求直接发往对应网站。网站看到的是你的网络出口 IP，与普通浏览行为一致。
5.4 **AI 客户端调用的外部地址**：AI 通过本应用发起的网络请求，目标与内容由该 AI 决定。
5.5 本应用不主动向任何开发者控制的服务器发送数据 —— 因为不存在这样的服务器。

## 六、访问令牌
6.1 访问令牌用于校验 HTTP 通道（上传、下载、网页控制台、静态站点）的调用方身份。
6.2 令牌保存在本机，只在你复制地址、或在客户端配置中填入时才离开设备。
6.3 令牌泄露等同于把文件读写权限交给他人。可在设置中重置令牌；重置后旧的客户端需要重新配置。
6.4 关闭令牌校验会让同网络内任何人都能访问 HTTP 通道，请自行评估。

## 七、日志与统计
7.1 运行日志（工具调用、审批、连接、错误）只保存在**内存**中，最多 800 条，应用进程结束后即消失。
7.2 日志记录的是操作摘要：时间、类型、工具名、路径与简短结果，**不记录文件正文**。
7.3 使用统计只记每日请求条数与运行时长，用于在 App 内绘制热力图。统计只在本机生成，不发送到任何服务器。
7.4 日志与统计都可以在应用内清空或重置。

## 八、备份文件
8.1 备份由你主动触发，内容可包含记忆库、设置、自定义工具、统计，以及（可选）访问令牌。
8.2 备份文件保存在你指定的位置，或你配置的第三方存储（如 WebDAV、S3）。
8.3 备份文件由你自行保管。它可能包含令牌与记忆内容，请勿放在他人可访问的位置。
8.4 本应用不保留备份文件的副本，也不会上传备份。

## 九、AI 客户端
9.1 本应用只是通道。AI 客户端读到什么、写到什么、发到哪里，由该客户端与你的授权决定。
9.2 AI 客户端自身的隐私政策由该客户端的提供方负责，不在本政策的范围内。
9.3 你可以通过权限页与工具包限制 AI 能看到的工具与目录范围。

## 十、第三方组件
本应用使用 AndroidX、Jetpack Compose、Kotlin、Shizuku、haze 等开源组件。它们在本机运行，不包含数据上报逻辑。

## 十一、未成年人
本应用是面向开发者的工具，不针对未成年人设计。若你未满法定年龄，请在监护人指导下使用。

## 十二、政策的变更
12.1 本政策可能随版本更新调整。重大变更会在应用内提示，并要求你重新确认。
12.2 变更后的政策自公布之日起生效。继续使用即视为接受。

## 十三、联系
对数据处理有疑问，可在 GitHub 仓库提 Issue：https://github.com/xtt-xt/MCPBox/issues
