# 04 · 记忆库

[← 返回 README](../README.md) ｜ [English](en/04-memory.md)

给 AI 的长期记忆。**一条记忆就是一个 Markdown 文件**，AI 直接整篇读写，你在 App 里也是整篇编辑。

```
files/memory/
  项目/MCPBox.md
  人物/星天.md
  未分类/随手记.md
  _backup/graph-20261121-161500.json    ← 旧版数据库的备份（迁移用）
```

- **名字** = 文件名，全局唯一。
- **分区** = 父文件夹，没有分区就直接放在记忆目录下，界面显示成「未分类」。
- 改名 = 挪文件，指向旧名字的关联会自动跟上；删掉一条，别处的关联也一并去掉。

## 文件格式

```markdown
---
title: MCPBox
description: 手机上的 MCP 文件服务器
type: 项目
created: 1763700000000
updated: 1763700000000
links:
  - to: 星天
    type: 属于
---

正文，随便写，Markdown 照常渲染。
```

| 字段 | 说明 |
|---|---|
| `title` | 记忆名，等于文件名（改这个不如直接改文件名） |
| `description` | 一句简介，列表、搜索结果、关联项里显示的就是它 |
| `type` | 类型，自由文本（项目 / 人物 / 偏好…） |
| `links` | 指向别人的关联，每项 `to` + `type`；指向**这篇**的关联不写在这，读取时反着扫出来 |
| 正文 | `---` 之后的一切 |

front-matter 只认这几个键，写错了不会坏数据，只是被忽略。手写、手改都行 —— 改完回到 App 会自动重新扫目录。

## 工具（7 个）

| 工具 | 作用 |
|---|---|
| `memory_list` | 列出记忆（分区 + 名字 + 简介），可按分区过滤 |
| `memory_read` | 读一篇：简介、类型、正文 + 双向关联（带对方简介） |
| `memory_write` | 整篇写入（不存在就新建）；`oldName` 用来改名 |
| `memory_append` | 往正文末尾追加一段 |
| `memory_search` | 关键词搜索，命中带直接邻居 |
| `memory_delete` | 删除若干篇 |
| `memory_stats` | 记忆数 / 关联数 / 分区 / 类型分布 |

总开关在「设置 → AI 与工具 → 记忆库」，关掉后这 7 个工具直接从 `tools/list` 消失。

## 在 App 里编辑

位置：**设置 → AI 与工具 → 记忆库**。

- 列表页：搜索（名字 / 简介 / 正文）、分区胶囊筛选、点卡片进详情；
- 详情页：名字、分区、简介、类型、正文、关联全部可改，右下角「保存」写回文件；
- 关联可以加（选对方 + 关系类型）和删（只删得出边，入边由对方那篇管）；
- 右上角「⋯」：导出全部记忆、从文件导入、导出最后旧版数据库。

## 导入 / 导出

都在 App 里手动做，不占工具名额。

| 操作 | 说明 |
|---|---|
| 导出全部 | 存成一个 zip，`memory/memory.json` 是清单，`memory/files/**` 是每个 md |
| 从文件导入 | 认 zip（本 App 导出的），也认旧版的 `graph.json` 裸 JSON |
| 导入方式 | 合并（保留现有）/ 覆盖（先清空） |

## 从旧版迁移

旧版记忆是 `files/memory/graph.json`（实体 + 观察 + 关系）。

- 根目录还躺着 `graph.json` 时，记忆库整页只显示一条「更新新版记忆数据库」横幅，工具也一律报错；
- 点横幅弹窗里三选一：**迁移** / **保存旧版记忆**（另存到自选位置）/ **稍后**（先关掉，记忆继续禁用）；
- 检测到旧版数据时会**自动备份**一份到 `files/memory/_backup/graph-<时间>.json`，页面会把路径写出来；
- 迁移：每个实体 → `<分区>/<名字>.md`，观察每句一行拼成正文，关系 → 起点那篇的 `links`，原 `graph.json` 删掉（备份还在）；
- 备份随时能在「⋯ → 导出最后旧版数据库」里取出来。

## 随备份一起走

「备份与恢复」里的记忆部分是**整目录**：zip 里 `memory/files/` 下就是那些 md，
`memory/memory.json` 只是清单。老备份里的裸 `graph.json` 恢复时也会自动转成 md。
见 [07 统计 · 备份 · 引导](07-统计备份与引导.md)。
