# 04 · 记忆库

[← 返回 README](../README.md) ｜ [English](en/04-memory.md)

给 AI 的长期记忆，结构是经典的知识图谱三元组：

| 概念 | 说明 |
|---|---|
| **实体** | 一个节点：项目、工具、事件、人物、用户偏好… **名字唯一** |
| **观察** | 挂在实体身上的一条条事实短句（重复的会自动跳过） |
| **关系** | 两个实体之间的有向边：`from ──PART_OF──▸ to` |

实体类型、分区（folder）、关系谓词都是**自由文本**，不强制枚举 —— AI 自己会自然长出
「项目事实 / 用户偏好 / 事件」这类结构，关系谓词一般用大写下划线（`PART_OF`、`HAPPENS_AT`、
`INVOLVES`、`CORRECTS`、`UPDATES`…）。

- **行为细节**：重名实体只跳过不覆盖；重命名会自动同步关系两端；删实体会连带删掉它的所有关系。
- **搜索**：`search_nodes` 命中实体会**连带返回直接邻居**，方便顺着线索往下读。
- **存储**：`filesDir/memory/graph.json`，原子写入（先写 `.tmp` 再改名），断电最多丢最后一次写入。
- **工具**：12 个 `memory_*` / 实体关系工具，见 [01 工具清单](01-工具清单.md#memory--记忆库10-个出厂开)。
- **总开关**：「设置 → AI 与工具 → 记忆库」关掉后，记忆类工具直接从 `tools/list` 消失。

## 在 App 里浏览和编辑

位置：**设置 → AI 与工具 → 记忆库**。

- 支持搜索、按分区过滤；
- 点进实体可以改**名字 / 类型 / 分区**，增删观察、增删关系；
- 点关系能跳到对方实体；
- 右上角「⋯」菜单里有**导出 / 导入**。

## 导出 / 导入

### 在 App 里

| 操作 | 说明 |
|---|---|
| 导出 | 走系统文件选择器（CreateDocument），存成一份 JSON |
| 导入 · 合并（默认） | 同名实体只补**空着的**类型 / 分区，观察去重后追加，绝不覆盖已有观察，重复的关系跳过 |
| 导入 · 覆盖 | 先清空整个记忆库，再写入文件内容（会二次确认） |

合并导入时「**未分类**」视同没填：导入文件带分区就补上，而用户显式选过的分区不动。

### 让 AI 做

两个工具（`memory_export` / `memory_import`）做同样的事：

- `memory_export`：把整库导出到指定 JSON 文件。
- `memory_import`：从 JSON 导入，`mode=merge`（默认、安全）/ `mode=replace`（清空后整份替换）。

> ⚠️ 这两个工具**目前不在任何工具包里**，所以不会出现在 `tools/list` —— 工具包只放行「包里的工具」。
> 现在要么用 `tools/call` 直接调，要么在 App 里操作。等它们被加进 `memory` 包后就会正常可见。
