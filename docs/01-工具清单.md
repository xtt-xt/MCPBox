# 01 · 工具清单

[← 返回 README](../README.md) ｜ [English](en/01-tools.md)

MCPBox 一共注册了 **72 个 MCP 工具**。它们按**工具包**分组（见 [03 工具包与会话](03-工具包与会话.md)）：
`tools/list` 只会返回「基础包 + 已激活包」里的工具，但 `tools/call` **不按包过滤** —— 直接按名字调也允许（照常走权限矩阵）。

「权限键」列是该工具走的权限开关（见 [02 权限与审批](02-权限与审批.md)）；同名权限键的默认值决定它会不会弹审批。

## core · 基础（4 个，常驻）

包管理工具（`list_packs` / `activate_pack` / `deactivate_pack` / `reset_packs` / `manage_pack`）也在这个包里，但**只有打开「让 AI 自己开关包」时才可见**，默认收起。

| 工具 | 权限键 | 说明 |
|---|---|---|
| `server_info` | `system.info` | 服务器状态：版本、端口、传输方式、根目录、权限设置、工具包、可用操作 |
| `get_device_info` | `system.info` | 手机型号、系统版本、电量、存储占用。**单个工具默认「询问」** |
| `notify_user` | `system.info` | 在手机上弹一条通知，用于告知任务完成或需要用户操作 |
| `get_token` | `system.info` | 取访问令牌、端口与可用地址。**调用它本身不需要令牌**，单个工具默认「询问」 |

## file.read · 文件读取（8 个，出厂开）

| 工具 | 权限键 | 说明 |
|---|---|---|
| `list_dir` | `fs.read` | 列目录（名称、类型、大小、修改时间），可按名称/大小/时间排序 |
| `directory_tree` | `fs.read` | 以缩进树展示目录结构，快速看清一个文件夹里有什么 |
| `file_info` | `fs.read` | 单个文件 / 目录的详情：大小、修改时间、读写权限、子项数量 |
| `read_file` | `fs.read` | 读文本文件（带行号，可分段读大文件；二进制会报错，图片用 `read_image`） |
| `read_image` | `fs.read` | 把手机上的图片读出来给模型看（png / jpg / gif / webp / bmp） |
| `search_files` | `fs.read` | 按文件名（通配符或正则）或文件内容（正则）搜索 |
| `file_hash` | `fs.read` | 计算 md5 / sha1 / sha256，用于比较两个文件是否相同 |
| `storage_info` | `system.info` | 当前可访问的根目录，以及各分区的总空间 / 剩余空间 |

## memory · 记忆库（10 个，出厂开）

关闭「记忆库」总开关后，这些工具会直接从 `tools/list` 里消失。

| 工具 | 权限键 | 说明 |
|---|---|---|
| `create_entities` | `memory` | 创建实体（节点）：项目、工具、事件、人物、用户偏好… 名字唯一 |
| `create_relations` | `memory` | 在两个实体之间建立有向关系（如 `PART_OF`） |
| `add_observations` | `memory` | 给已有实体追加「观察」—— 一条条事实短句，重复会自动跳过 |
| `read_graph` | `memory` | 读取记忆库全部内容（实体 + 关系），可按分区 / 类型过滤 |
| `search_nodes` | `memory` | 关键词搜索，命中实体会**连带返回它们的直接邻居**，方便顺线索读 |
| `open_nodes` | `memory` | 按名字精确读取若干实体的完整内容（观察 + 关系） |
| `memory_stats` | `memory` | 记忆库规模：实体数、关系数、分区 / 类型 / 关系谓词分布 |
| `delete_entities` | `memory` | 删除实体（与它相连的关系一并删除） |
| `delete_relations` | `memory` | 删除指定的关系 |
| `delete_observations` | `memory` | 删除某个实体上的若干条观察（需一字不差给出原文） |

> ⚠️ **`memory_export` / `memory_import` 当前不在任何工具包里**，所以不会出现在 `tools/list`
> （工具包只放行「包里的工具」）。目前只能用 `tools/call` 直接调，或在 App 的
> 「记忆库 → ⋯ → 导出 / 导入」里做同样的操作。详见 [04 记忆库](04-记忆库.md)。

## file.write · 文件写入（9 个，出厂关）

| 工具 | 权限键 | 说明 |
|---|---|---|
| `write_file` | `fs.write` | 创建 / 覆盖 / 追加文件（也支持 base64 写二进制），自动创建上级目录 |
| `edit_file` | `fs.write` | 查找并替换文件内容（精确或正则，可全部替换），比整文件重写安全 |
| `make_dir` | `fs.write` | 创建目录（默认连同上级一起创建） |
| `copy_path` | `fs.write` | 复制文件或整个目录 |
| `move_path` | `fs.write` | 移动文件或目录，也可用来重命名 |
| `delete_path` | `fs.delete` | 删除文件或目录（目录需显式递归）；默认进回收站 |
| `list_trash` | `fs.read` | 列出回收站里的文件，AI 误删的可以在这里找回 |
| `restore_trash` | `fs.write` | 把回收站里的文件还原回原位置或指定位置 |
| `empty_trash` | `fs.delete` | 彻底清空回收站（不可恢复） |

## shell · 命令与自定义工具（8 个，出厂关）

| 工具 | 权限键 | 说明 |
|---|---|---|
| `run_shell` | `shell.exec` | 在手机上执行一条 Shell 命令并返回输出，就像在 Termux 里敲。危险命令会弹审批；`timeoutMs=0` 表示不限时 |
| `shell_info` | `system.info` | 可用的执行后端（应用沙箱 / Root / Shizuku）、当前身份、环境变量、超时设置 |
| `create_custom_tool` | `tools.manage` | 给自己造一个新的 MCP 工具：名称、说明、参数、命令模板（`{{参数}}` 占位） |
| `update_custom_tool` | `tools.manage` | 修改已有的自定义工具 |
| `delete_custom_tool` | `tools.manage` | 删除一个自定义工具 |
| `list_custom_tools` | `system.info` | 列出所有自定义工具及其定义（据此修改或导出） |
| `export_custom_tools` | `fs.write` | 把所有自定义工具导出成一个 JSON 文件 |
| `import_custom_tools` | `tools.manage` | 从 JSON 文件导入自定义工具（同名更新） |

## ui · UI 自动化（8 个，出厂关，需 Root / Shizuku）

截屏、读控件树、注入点击都是系统权限，应用自身 UID 做不到，所以这一包需要 Root 或 Shizuku。
读界面结构时会在所有可用的特权后端之间**自动回退**（root 优先）。

| 工具 | 权限键 | 说明 |
|---|---|---|
| `ui_screenshot` | `ui.control` | 截屏并把画面给模型看（可保存到手机文件） |
| `ui_dump` | `ui.control` | 读界面结构：控件树 / 可交互元素与它们的页面坐标 |
| `ui_tap` | `ui.control` | 点击屏幕上某个坐标 |
| `ui_swipe` | `ui.control` | 滑动 / 滚动 |
| `ui_input` | `ui.control` | 往输入框里输入文字（输中文自动走「写剪贴板 → 模拟粘贴」） |
| `ui_key` | `ui.control` | 按系统按键（返回 / 主页 / 最近任务 / 回车…） |
| `ui_launch` | `ui.control` | 启动应用，或查看当前前台应用 |
| `ui_wait` | `ui.control` | 等某个元素 / 文字出现（或消失） |

## browser · 内置浏览器（18 个，出厂关，不需要 Root）

页面跑在 App 自己的 WebView 里，登录态与系统浏览器隔离，只属于 MCPBox。
URL 默认**禁内网与 localhost**，防止网页脚本去调本机的 MCP 端口。有页面时手机上会出现悬浮球。
默认每个动作都过一次审批（权限键 `browser.control` 默认「询问」）。

| 工具 | 权限键 | 说明 |
|---|---|---|
| `browser_open` | `browser.control` | 新开一个页面并加载网址；可指定这一页的身份（手机版 / 桌面版）与 cookie |
| `browser_navigate` | `browser.control` | 让已有页面跳到新网址（连续走几个链接时比反复开页面省内存） |
| `browser_history` | `browser.control` | 前进 / 后退 / 刷新 |
| `browser_pages` | `browser.control` | 列出所有打开的页面，并标出当前页面 |
| `browser_switch` | `browser.control` | 把某个页面切成「当前页面」（悬浮窗也会显示它） |
| `browser_close` | `browser.control` | 关掉指定页面，或全部关闭 |
| `browser_content` | `browser.control` | 读页面内容：正文纯文本 / Markdown / 可交互元素（带坐标）/ 链接 / HTML / 元信息 |
| `browser_click` | `browser.control` | 点页面上的元素（按序号 / 文字 / CSS 选择器 / 坐标） |
| `browser_input` | `browser.control` | 往输入框 / 文本域 / 下拉框 / 勾选框里填值（React / Vue 受控组件也认），可顺手提交 |
| `browser_scroll` | `browser.control` | 滚动页面（到底 / 回顶 / 指定位置 / 翻几屏 / 滚到某元素） |
| `browser_wait` | `browser.control` | 等某个选择器或文字出现 / 消失，比死等几秒稳 |
| `browser_eval` | `browser.control` | 在页面上下文里执行一段 JS（兜底手段，走页面自己的登录态） |
| `browser_screenshot` | `browser.control` | 把页面渲染成图片给模型看（页面藏在后台也能拍） |
| `browser_search` | `browser.control` | 用搜索引擎查东西（必应 / 百度 / Google / DuckDuckGo / 知乎 / 微博 / B 站 / GitHub / 维基…） |
| `browser_save` | `fs.write` | 把页面内容存成手机上的文件（markdown / text / html） |
| `browser_storage` | `browser.control` | 管登录态与身份（**按页面**）：读 / 写 cookie、清某个站点的 cookie、清缓存、看 / 改 UA |
| `browser_engines` | `browser.control` | 看 / 加 / 删搜索引擎（自己加的写进设置） |
| `browser_download` | `fs.write` | 把 http(s) 链接直接下载到手机（图片 / PDF / zip / 文本），不走浏览器 |

## my.tools · 我的工具（动态，出厂关）

用户在 App 里（或让 AI 用 `create_custom_tool`）创建的自定义工具，会自动归进这个包。
包内容是动态的：有多少自定义工具，包里就有多少个。

## 相关的打包工具

| 工具 | 权限键 | 说明 |
|---|---|---|
| `list_packs` / `activate_pack` / `deactivate_pack` / `reset_packs` | `system.info` | 查询与切换工具包可见性，**免审批**（它们不扩大实际能力，真正拦人的是权限矩阵） |
| `manage_pack` | `tools.manage` | 新建 / 修改 / 删除自定义工具包 |
