# 05 · 文件通道与静态站点

[← 返回 README](../README.md) ｜ [English](en/05-file-transfer-and-web.md)

## 上传 / 下载（不依赖 root，也不需要数据线）

```bash
# 推文件进手机（原始 body 即文件内容）
curl -X POST --data-binary @app.apk \
  "http://<手机IP>:8720/upload?path=/storage/emulated/0/xtt/app/mcp/app.apk&token=<token>"

# 取文件出手机
curl -o back.apk \
  "http://<手机IP>:8720/download?path=/storage/emulated/0/xtt/app/mcp/app.apk&token=<token>"
```

- 令牌三种带法都认：`?token=` / `Authorization: Bearer` / `X-MCP-Token`。
- **上传走「写文件」权限、下载走「读文件」权限**，照旧弹审批。
- 单次上限 = 设置里的「最大上传大小」`maxUploadMb`（默认 **512MB**）。

### 浏览器上传网页

手机浏览器打开 `http://127.0.0.1:8720/upload` 就有一个上传页：可以**多选文件**、填目标路径，
还有一个「这是压缩包」勾选框（勾上等于带上 `extract=1`）。

### 整目录一次传 / 一次取（zip）

一个请求 = **一次审批**（别循环传 N 个文件，会弹 N 次审批）：

```
POST /upload?path=<目标目录>&extract=1     body 是 zip → 解压到该目录
GET  /download?path=<目录>&zip=1           目录 → 打包成 zip 返回
```

上传压缩包时会先做校验，再弹审批，批准后才真正落盘：

- 条目数 ≤ **20000** 个文件
- 解压后总大小 ≤ `maxUploadMb × 4`
- 拒绝 `../`、绝对路径、盘符这类不安全的条目名

## 静态站点托管

把网页产物直接放进手机，浏览器打开就能看 —— 不用数据线、不用另起服务器：

```
http://127.0.0.1:8720/web/?token=<令牌>                        打开站点列表
http://127.0.0.1:8720/web/xtt/web/flat-ui/index.html?token=<令牌>
```

- **路径相对「主根目录」**：`/web/a/b.html` 就是 `<主根目录>/a/b.html`。
- 目录会生成一张索引页，其中的 `index.html` 会被标成「这个目录的入口页」。
- **要访问令牌，但只用带一次**：第一个请求的地址里放 `?token=…`，服务器就给浏览器种一个
  `Path=/web` 的 HttpOnly 会话 cookie（**12 小时**有效，服务重启即失效）。页面里的 CSS / JS / 字体
  这些子资源由浏览器自动带 cookie —— 这正是不能只靠 `?token=` 的原因（浏览器自己去要子资源时，
  不会把地址栏里的 query 带过去）。不想手输令牌：从**网页控制台**的「静态站点」卡片点进去，
  那个链接自带令牌。
- **只读**：没有 PUT / DELETE，写文件仍然只能走 `/upload`（那条路要过审批）。
- `<主根目录>/.MCPBox`（App 自己的目录，含回收站）不给看；索引页也不列隐藏项。
- 单文件上限 **32MB**（预览是整个读进内存再发的）；更大的文件用 `/download` 取出去看。
- 权限口径：只有 `fs.read` 的**「拒绝」**能拦住它（「询问」不弹窗 —— 一个页面几十个子资源，逐个审批没法用）。
- 把令牌功能整个关掉（`tokenEnabled=false`）时，这条路由跟着放开，口径与 `/download` 一致。

## 网页控制台安全

| 开关 | 作用 |
|---|---|
| 仅本机访问 | 只响应 `127.0.0.1` / `::1`，局域网设备一律 403（默认关） |
| 密码保护 | 浏览器需登录（cookie 会话 12 小时）；程序用 token 调用不受影响（默认关） |
| 访问密码 | 单独设置，留空则用访问令牌（token）当密码 |

网页控制台本身在 `http://127.0.0.1:8720/`：能在浏览器里试工具、看日志、处理审批、进静态站点。

## 相关的 HTTP 路由一览

| 路由 | 用途 | 鉴权 |
|---|---|---|
| `/mcp`、`/mcp/p/<名字>` | MCP（Streamable HTTP） | 令牌 |
| `/sse` + `/messages` | MCP（旧版 HTTP+SSE） | 令牌 |
| `/upload` | 上传（支持 `extract=1` 解压） | 令牌 + 审批 |
| `/download` | 下载（支持 `zip=1` 打包） | 令牌 + 审批 |
| `/web/<路径>` | 静态站点（只读） | 令牌（一次，随后靠 cookie） |
| `/` | 网页控制台 | 可选仅本机 / 密码 |
| `/api/status`、`/api/tools`、`/api/log`、`/api/call`、`/api/pending`、`/api/approve` | 网页控制台用的 JSON 接口（含待审批列表与批准 / 拒绝） | 令牌 |
