## 使用统计

位置：**设置 → 应用 → 统计**。全是**只增不减**的长期记录：

| 指标 | 口径 |
|---|---|
| **请求热力图** | `POST /mcp` 的每条 JSON-RPC 消息算一次（含 `initialize` / `ping` / 通知），按设备本地自然日分组 |
| **累计运行时长** | 服务器在跑就累加；页面上每秒刷新 |
| **打开应用次数** | 每次打开 App 记一次（一个进程一次，转屏 / 切回任务不算） |
| **服务器启动次数** | 每次服务启动（含重启）记一次 |
| **有请求的天数** | 一年里有多少天有请求 |

- 存储：`filesDir/stats/stats.json`，原子写入；请求按 **15 秒**批量落盘，进程被杀最多丢十几秒。
- **永远保留**：不放在 `SharedPreferences` 里，「重置全部设置」也**不会清掉**（也没有清空入口）。
- 备份里的第四部分是统计；恢复时合并 = **按天取较大值**（连着恢复两次不会翻倍）。

## 备份与恢复

位置：**设置 → 应用 → 备份与恢复**。四部分：

| 部分 | 内容 |
|---|---|
| 记忆库 | 实体 / 观察 / 关系 |
| 设置 | 全部设置键值（**可选**是否包含访问令牌） |
| 自定义工具 | 工具定义 |
| 统计 | 请求次数 / 运行时长 / 启动次数 |

- **导出**：可以打成一个 **zip**（`manifest.json` + `memory.json` + `settings.json` + `custom-tools.json` + `stats.json`），也可以逐个部分导出 JSON。备份页用**开关**挑内容，令牌是「设置」下面的附属行（关掉设置时一起收起）。导出时选目录，文件名形如 `memory-20261001-0030.json`。
- **恢复两步走**：
  1. 选要恢复的部分（zip / 多文件走这步；单文件会跳到第 2 步）；
  2. 每个部分各自选「**合并 / 覆盖**」（一个胶囊切换）。
- **设置永远是整份覆盖**（不问模式）；记忆库 / 自定义工具只有「当前非空」时才问合并还是覆盖。
- **令牌策略**：备份时可以选含不含 token；恢复时如果备份里带 token，会出现一个「连访问令牌一起恢复」开关，**默认关** —— 免得恢复个备份把所有 MCP 客户端踢下线（它们地址里带着旧 token）。
- **嗅探规则**：单文件靠 `_type` 字段识别（`mcpbox.settings` / `mcpbox.custom-tools` / stats）；记忆文件没有 `_type`，靠有没有 `entities` / `relations` 猜 —— 这样**老版本（1.1.0-55）的备份也认得**。

## 初始引导

全新安装第一次打开走五步：**欢迎 → 语言 → 权限 → 恢复备份 → 开始使用**。

- 升级安装**不会**打扰你（只在第一次安装时出现）。
- 想再看一遍：开发者在**关于页连点图标 7 次**解锁「开发者模式」，里面可以强制重走引导。

## 开发者模式

关于页连点图标 7 次解锁。里面可以：

- 强制重走初始引导；
- 预览「发现新版本」弹窗（跳过版本比较，本地开发版也能看到弹窗）；
- 下次启动强制检查更新；
- 「语言菜单」开关：打开后语言下拉里才会出现隐藏语言（默认关）。

> 关于页的「检查更新」点整行就会检查；查到新版会弹「发现新版本」，已是最新或失败只弹一条 toast。
> 提示：日常开发构建的 `versionName` 一直是发布版本（只在发版时变），所以本地版手动检查会显示
> 「已经是最新版」——要看弹窗请用开发者模式的「预览更新弹窗」。

## 多语言

- 内置**中文 / English**，切换后整个界面与**全部工具**的标题、说明、参数说明都会跟着变。
- 想翻译成别的语言：导出语言模板 → 改词条 → 导入。
- 语言选择在 **设置 → 外观与语言**。
