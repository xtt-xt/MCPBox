# MCP 文件盒 · MCPBox

**中文** | [English](README.en.md)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![构建与签名](https://github.com/xtt-xt/MCPBox/actions/workflows/build.yml/badge.svg)](https://github.com/xtt-xt/MCPBox/actions/workflows/build.yml)

把 Android 手机变成一台 **MCP 文件服务器**：AI 客户端（RikkaHub / Claude Desktop / Cursor / Cline…）通过 MCP 协议读写手机文件、执行命令、控制浏览器与界面，而**每一次敏感操作都要经过手机上的审批**。

```
AI 客户端 ──HTTP(MCP)──▶ 手机上的 MCPBox ──▶ 文件系统 / shell / 浏览器
                              │
                              └─▶ 审批（悬浮窗 / 通知栏）：允许一次 / 始终允许 / 拒绝 / 始终拒绝
```

- **单 APK，无外部依赖**：HTTP/MCP 服务器、自带浏览器、常驻终端全在这一个进程里
- **三档 shell 身份**：应用沙箱 / Root / Shizuku（ADB shell）
- **权限不是「一次性全允许」**：9 个权限键三态 + 路径 / 命令级规则 + 单工具四态

## 快速开始

1. 装 APK，打开 App，首页点开服务（默认端口 `8720`）
2. 给文件访问 / 悬浮窗 / 通知权限 —— 首页「环境检查」会逐项提示。
   有 Root / Shizuku 时，文件访问 / 悬浮窗 / 忽略电池优化进 App 会**自动补齐**，也可点「一键补齐」；通知权限要自己在系统弹窗里点一下
3. 在 AI 客户端里添加 MCP 服务器：

```
类型：Streamable HTTP（推荐）或 SSE
地址：http://<手机局域网IP>:8720/mcp
令牌：用 App 首页「复制地址」拿到的完整 URL（自带 token）
```

4. 要用的工具包在「**权限 → 工具包**」里勾选（默认给 22 个工具）；
   需要命令 / 界面控制时，去「终端」页申请 Shizuku 授权（Root 会自动识别）

> 主流 MCP 客户端只在连接时拉一次工具列表 —— **改完工具包要重连客户端（或重启 App）** 才生效。
