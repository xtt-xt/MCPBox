[![最新版本](https://img.shields.io/github/v/release/xtt-xt/MCPBox?label=release)](https://github.com/xtt-xt/MCPBox/releases/latest)

把 Android 手机变成一台 **MCP 服务器**：AI 客户端通过 MCP 协议读写手机文件、执行命令、控制浏览器和界面。不需要电脑，也不需要 Termux。

**每一次敏感操作都要在手机上点一次同意** —— 允许一次 / 始终允许 / 拒绝 / 始终拒绝。

```
AI 客户端 ──HTTP(MCP)──▶ 手机上的 MCPBox ──▶ 文件 / 终端 / 浏览器
                              └──▶ 审批（悬浮窗 / 通知栏）
```

- **一个 APK**：MCP 服务器、终端、浏览器都在同一个进程里
- **三档执行身份**：应用沙箱 / Root / Shizuku，用到才提权
- **默认最小暴露**：AI 开局只看到 22 个工具（全量的三成），需要时再开包

## 下载

[Releases](https://github.com/xtt-xt/MCPBox/releases/latest) 里下载 `MCPBox-v1.4.0-151-release.apk`（约 3.9 MB）。

- 系统要求：Android 8.0（API 26）及以上
- 不需要 Root；执行命令和界面控制才需要 Root 或 Shizuku

## 快速开始

1. **启动服务**：打开 App，首页点开服务，默认端口 `8720`
2. **授权**：首页「环境检查」会逐项提示。有 Root / Shizuku 时，文件访问、悬浮窗、忽略电池优化会在打开 App 时自动补上；通知权限要在系统弹窗里自己点一下
3. **拿地址**：首页「复制地址」，得到自带令牌的完整 URL
4. **在客户端添加 MCP 服务器**：

```
传输方式：Streamable HTTP（推荐）或 SSE
地址：    http://<手机局域网 IP>:8720/mcp
令牌：    已包含在上面的地址里
```

5. **按需开工具包**：「权限 → 工具包」。要执行命令或控制界面，到「终端」页申请 Shizuku（Root 会自动识别）

> 客户端只在连接时拉一次工具列表 —— 改完工具包要**重连客户端或重启 App** 才生效。

## 支持的客户端

任何支持 **Streamable HTTP**（MCP 2025-06-18）或 **SSE** 的客户端都能连，例如 RikkaHub、Claude Code、Cursor、Cline。只支持 stdio 的客户端（如桌面端 Claude）可以借助 `mcp-remote` 之类的桥接。

要填的就三样：地址 `…/mcp`、访问令牌、传输方式。

## 与常见做法比较

| 方案 | 需要什么 | 审批 | 局限 |
|---|---|---|---|
| 在 Termux 里自己跑 MCP 服务器 | 手动配 Python / Node 环境 | 没有，脚本拿到什么权限就是什么权限 | 每次重装都要折腾一遍，重启后要自己拉起来 |
| 电脑上跑服务器，手机文件同步过去 | 一台常开的电脑 | 在电脑上 | 手机离线就断，文件还要来回同步 |
| **MCPBox** | 一个 APK | **每次敏感操作都要在手机上点** | 只有 Android；命令与界面控制仍需 Root / Shizuku |

## 常见问题

**需要 Root 吗？**
不需要。读写文件、记忆库、内置浏览器、静态托管开箱即用；执行命令和界面控制才要 Root 或 Shizuku。

**会不会把文件传到别的地方？**
不会。没有账号、没有开发者服务器、没有上报组件；数据都在应用私有目录，只有拿着访问令牌的客户端能调用工具。

**锁屏或切到后台还跑吗？**
前台服务 + 唤醒锁，锁屏照常工作。被系统省电策略回收后不会自己复活 —— 那本来就不是这个 App 的功能，建议把它加进电池优化白名单。App 被划掉后不保证继续运行。

**局域网里的电脑连不上？**
先看「设置 → 网络与访问 → 允许局域网访问」开着没有；再确认路由器没开 AP 隔离或把设备放进了访客网络；端口可以在同一页改（1024–65535）。

**改了工具包，AI 还是看不到新工具？**
客户端只在连接时拉一次工具列表，重连客户端或重启 App 就好。

**忘了令牌怎么办？**
首页「复制地址」随时能看；也可以在「权限 → 远程访问」里重置，旧令牌立刻失效，记得同步改客户端配置。

**卸载会丢数据吗？**
会。设置、记忆库、统计都在应用私有目录，卸载即删；要留就先去「设置 → 应用 → 备份与恢复」导出一份。

```bash

./gradlew :app:assembleRelease  # 正式包
```
